# Activity 06 - Turn a Sprint Review into Stakeholder Collaboration

**Course:** Scrum Master Fundamentals for High-Performing Teams  
**Course Code:** TGS-2024045803  
**Alignment:** K2, K4, A1, A5  
**Version:** v6.0 | 22 August 2026

## Purpose

Apply Scrum Master judgement to a realistic workplace scenario and produce evidence that meets explicit acceptance criteria.

## Folder contents

- `README.pdf` - this detailed step-by-step guide
- `SCENARIO.pdf` - scenario, roles, questions, and constraints
- `worksheet.xlsx` - editable evidence workbook
- `mock-data.csv` - starter evidence for the workbook and Scrum tool
- `CHECKLIST.pdf` - acceptance and submission checks

## Before you start

1. Open the Scrum activity tool: https://alfredang.github.io/scrum/
2. Open `worksheet.xlsx` and read the Instructions sheet.
3. Open `SCENARIO.pdf` and assign the listed roles.
4. Import or copy `mock-data.csv` only where the worksheet instructs you to do so.
5. Save a working copy as `Activity-XX-<TeamName>.xlsx`.

## Detailed procedure

1. Review the Increment evidence and customer mock data.
2. Design a working-session agenda around outcome, environment, and options.
3. Invite stakeholders to inspect evidence and surface changed assumptions.
4. Facilitate conflicting views without promising all requests.
5. Adapt Product Backlog ordering with the Product Owner accountable.
6. Capture learning and the next validation step.

## Tool evidence

1. Capture the selected Scrum tool view or result in the worksheet Notes column.
2. Record the evidence used, the decision made, the accountable owner, and the review trigger.
3. Treat the tool as an information radiator; explain any judgement that differs from a score or prompt.

## Evidence to submit

- Sprint Review agenda
- Stakeholder feedback map
- Adapted backlog rationale

## Expected result

A reviewer can trace every recommendation to scenario evidence, a Scrum accountability or commitment, and a measurable adaptation decision.

## Troubleshooting

- If the tool does not load, refresh once and continue with the workbook; the activity remains fully usable offline.
- If a score looks surprising, check missing data and explain the discrepancy instead of overwriting it.
- If the team cannot agree, record the competing hypotheses and identify the accountable decision-maker.
- If a required workbook cell is blank, return to the Instructions sheet and complete the named evidence row.
