# Course Activities

This folder contains ten self-contained learner activity packs for **TGS-2024045803 — Scrum Master Fundamentals for High-Performing Teams**.

Each activity folder contains:

- `README.md` and `README.pdf` — purpose, preparation, detailed procedure, tool guidance, evidence, and troubleshooting
- `SCENARIO.md` and `SCENARIO.pdf` — scenario, role briefs, and learner questions
- `CHECKLIST.md` and `CHECKLIST.pdf` — acceptance and peer/trainer review checklist
- `worksheet.xlsx` — editable evidence workbook
- `mock-data.csv` — scenario data for analysis or import

Use the browser-based [Scrum activity tool](https://alfredang.github.io/scrum/) where instructed. Complete each checkpoint in the workbook and retain the evidence named in the activity README.

## Activity sequence

1. Diagnose Scrum Foundations at HarborHealth
2. Create Accountabilities and Working Agreements
3. Coach a Team Through an Impediment
4. Facilitate Sprint Planning and a Sprint Goal
5. Redesign the Daily Scrum Around Flow
6. Turn a Sprint Review into Stakeholder Collaboration
7. Interpret Burn Charts and Flow Metrics
8. Run an Evidence-Based Retrospective
9. Order a Product Backlog with Customer Evidence
10. Capstone Scrum Master Facilitation Plan
